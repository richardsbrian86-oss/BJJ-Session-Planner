# SEO Strategy

## In scope
- Public client booking portal routes under `/book/`
- Instructor directory page (`/book/`)
- Public instructor profile pages (`/book/:slug`)
- Public booking-related routes that a search or social crawler can fetch (`/book/:slug/book`, `/book/:slug/success`, `/book/booking/:token`)
- Crawlability files and shared portal shell affecting the public portal

## Out of scope
- Authenticated client dashboard behavior beyond source-visible SEO side effects (`/book/dashboard`)
- Instructor mobile app (`artifacts/mobile/**`)
- Internal API implementation except where it affects crawlability, route status behavior, or public URL generation
- Admin and instructor-only routes

## Target audience
- People looking to book Brazilian Jiu-Jitsu private training sessions
- BJJ instructors creating a public booking page

## Primary keywords
- BJJ private lessons
- Brazilian Jiu-Jitsu coach
- BJJ private training
- Book a BJJ instructor
